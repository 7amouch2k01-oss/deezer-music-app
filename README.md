# Deezer Music App

## Overview

This is a web-based music player application that integrates with the Deezer API to allow users to search for tracks, play previews, manage a queue, and control playback. It features a modern, responsive design and includes functionalities like shuffle, repeat, volume control, and a liked songs list.

## Features

*   **Music Search**: Search for tracks using the Deezer API.
*   **Playback Control**: Play, pause, skip forward, and skip backward through tracks.
*   **Queue Management**: View and manage the current playlist queue.
*   **Shuffle & Repeat Modes**: Enjoy music with shuffle playback or repeat individual tracks/playlists.
*   **Volume Control & Mute**: Adjust volume and mute/unmute playback.
*   **Like Songs**: Mark songs as liked and save them locally.
*   **Progress Bar**: Visual representation of track progress with seeking functionality.
*   **Responsive Design**: Optimized for various screen sizes.
*   **Keyboard Shortcuts**: Control playback and features using keyboard shortcuts.
*   **Top Tracks Display**: Shows a list of top tracks for a given search query.

## Technologies Used

*   **HTML5**: For the structure of the music player.
*   **CSS3**: For styling, animations, and responsive layout.
*   **JavaScript**: For all interactive functionalities, Deezer API integration, and playback logic.
*   **Deezer API**: To fetch music data, including track previews, album art, and artist information.
*   **Web Audio API**: For audio playback and control.
*   **Local Storage API**: To persist liked songs.

## Installation and Usage

To run this application locally:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/7amouch2k01-oss/deezer-music-app.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd deezer-music-app
    ```
3.  **Open `index.html`**: Open the `index.html` file in your web browser. No server-side setup is required.
